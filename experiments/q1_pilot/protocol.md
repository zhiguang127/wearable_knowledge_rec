# Q1 Pilot 研究契约 v1

本次是问题验证，不提出算法。config.json 的 canonical SHA-256 是契约 ID；运行开始前将配置、实现和官方源码哈希写入只增不改的私有 run manifest。保留所有失败运行，禁止回写发布、迁移报告或历史结果。

主目标是 K006 与 K017 的连续分差，所有候选同时评分。P1 五候选先闭环；A1 duration_and_timing 四候选是预定扩展。两种手写政策均不代表医学最优或独立真实推荐器；外部真实排序器缺口保持 BLOCKED。使用全体窗口，按 config 的覆盖门槛筛选，不使用 Silver、Gold、模型调用或训练。

来源是六个互斥七日块，八组敏感性将当前期两周分别拆为 4+3 日。有效 sleep 必须有数值和 infoCode=0；缺测/质量标记原样保留。原 RHR=0 不进入生理统计。时钟采用圆周统计，不补造时区。无有效统计时使用明确的中性政策特征并保留覆盖信息，绝不把原 null 写成零。

donor 是目标窗口 baseline 四个整周中最近的合格周，敏感性为最早合格周，每周至少五个有效睡眠和起始时钟日。donor 全在当前期之前，重复映射至六周；不是六个独立背景样本。每个时间块的全部模态、缺测和质量一同替换，保留目标相对日、星期与 phase。无 donor 标 DONOR_UNAVAILABLE；不跨人，不读取未来窗。重复一周导致周期性、连接处不自然和来源复用是明确限制；记录睡眠边界跳变、覆盖差和活动总分钟超 1440 等测量一致性指标，不称生理可实现干预。

节点来源替换游戏与独立派生特征游戏分开。精确枚举 64/256 coalition。RankingSHAP 保留官方整列表共同遮蔽，margin callback 是 TASK_ADAPTED；原生 Kendall 目标另报。ShaRP 官方 diff QoI 解释 margin，实际 pair outcome/rank/top2 wrapper 各有独立精确参考，不把它们叫原生 item-row 偏好。Shapley Flow 显式构造原始组选择器到各统计特征再到全部候选评分和 margin 的 DAG，内部边游戏只检验合法切边和守恒，不与节点 SHAP 排名。均检查官方原生样例，固定源码 commit，不修改官方源码。

先做行为控制，再做归因。行为诊断包含仅历史/仅当前 sleep 平移、仅时钟交替变化、保均值排序变化、未使用 context 改变和 item-only。人工变换只验证机制。主分析枚举所有 coalition，低预算误差是有限采样诊断，不是新算法动机。相同缓存策略为每个方法/种子/预算独立冷缓存；初始化、重复查询与实际计算分别计量。Flow 的节点重算量与端到端查询另列，不能硬拼预算冠军。

按参与者聚类汇总、bootstrap；失败/排除完整入分母。最高归因删除不翻转不算失败。保留至少逐块删除的留出行为检查，但其与 Shapley 的关系为描述统计。全自动数值实验无健康准确率、临床收益或人工一致率。只能在强方法正确适配、同游戏残余误差超噪声且不能由常规修复解决时考虑 Gate 1/2。透明评分器结果不能完成外部有效性确认，整体允许 INCONCLUSIVE；没有残余失败则明确不支持新算法，即使外部验证仍缺失。
