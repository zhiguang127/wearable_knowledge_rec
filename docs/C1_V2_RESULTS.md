# C1 Benchmark V2 本轮实际结果

**历史结果的解释已修正**：本文保留 V2.1 原轮次记录。后续审计确认，有损语义去重、联合条件验证限制、映射依赖的证据输入及采样影响了研究结论。本文的“可用个人标签不足”不能用来推断真实数据缺乏有价值证据，“没有确认联合条件”不能用来推断联合条件不存在。修复后的逐项比较见 [V2.2 审计报告](C1_V2_2_AUDIT_AND_REPAIR.md)。原始标签和冻结报告未改写。

2026-10-19。数据发布 V2.1，包含用户补充的 14 天冷启动。所有自动审查和标签均为 QWEN_PLUS_SILVER；没有人工 Gold、专家验证、推荐准确率或临床效果结论。完整机器汇总见 [aggregate_report.json](c1_v2_artifacts/aggregate_report.json)，质量报告见 [qa_report.json](c1_v2_artifacts/qa_report.json)，逐条非个人知识元数据见 [knowledge_index.jsonl](c1_v2_artifacts/knowledge_index.jsonl)。

活跃知识平均并不都有可穿戴依赖：条件数中位 2、可执行探查引用数中位 0，最多 12 个统计视角。10 条知识有多个探查引用，只是候选依赖；经当前数据能力检查，没有通过的“必要 ALL 且多探查”组，更没有确认的延迟发现收益。模型判重可能过度或遗漏，133 是当前模型审查/判重规则的产物，不能视为人工确定的真实独立知识总数。

窗口有效观测比例中位数：睡眠时长 97.22%、步数 100%、运动小时 64.29%、HRV 0%。`bed_time_std` 的数值覆盖虽为 100%，上游回看范围未知，不能因此声称作息条件可核验。全部每人/每窗覆盖明细保存在私有评估工件；公开报告只给聚合分布，重叠窗口不当独立样本。按历史长度，整批 288 探查的中位耗时约 19.46/24.76/29.35/36.85 ms。

规模比较使用与标签无关的 SHA256 嵌套顺序。候选池 26/100/300/500 请求规模实际为 26/100/300/402；活跃池实际为 26/100/133/133。候选 402 条全对三元词 Jaccard≥0.6 检出 1 对；活跃池该词面规则为 0 对，**不能推断语义重复率为 0**。Qwen 另外只审查最近三个邻居，最终仅对接受集内声明重复进行 canonical 化，所有原条目/判断保留。

个人标签中 119/120 仍需复核，说明本轮自动标注质量和背景可辨识性不足。它们不是 119 个错误推荐，也不能据此计算模型推荐失败率。JSON 引用缺失值的校验器曾把合法 null 缺失证据误拒；已以 `c1-v2-evidence-missingness-3` 离线修正，允许 null 仅支持不足信息，所有确定标签仍须有已计算数值。旧冻结发布和错误原因保留，没有重新调用模型或把未接受结果强行改成有效标签；修正后接受数仍为 1。

当前主要不利结论是：**全量计算足够便宜，知识数量未达标，可信联合必要证据与可用个人适用性标签不足。** 这些结果不能支持 KUV 的必要性或优势。本轮不实现新算法，不进行 RL、非贪心 AFA 或 baseline 竞争，提交 Draft PR 后停止。下一步应先评估是否值得补充适合的观测/上下文和来源、改进自动审查的可辨识性及验证质量，再决定研究方向；不能通过删数据、改写条件或限制全量计算制造问题。
