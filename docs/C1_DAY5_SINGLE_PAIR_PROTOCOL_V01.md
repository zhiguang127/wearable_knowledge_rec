# Day 5 — 单配对证据判别闭环协议 v0.1

本轮先复验 Day 4 所有封存目录、48 份原始轨迹、原版失败和 r1、来源与真实/合成边界，再固定本协议及代码。没有新标签前按配置固定选对顺序；不依据分数、预计收益或评审结果更换配对。原始 Day 1–4 工件与 README 都不修改。

## 来源准入与目标

优先 P4-07：See a Doctor / Daytime Habits。只有完整来源与锚点一致、存在条件—动作关系、内容可区分、条件能直接测量且不预设相对顺序，才进入单配对独立评审。若来源失败，按 P4-01、P4-08、P4-02 顺序做同样审查；都不合格则停止选对。没有“至少一条必须成功”的门槛。

咨询建议的源文触发、教育相关性与先读哪一条是三个问题。源文的 if 不是 only if，也没有声明咨询教育必须先于习惯教育。否认选定困扰不等于整条咨询知识不适用；未知症状也不是无症状。条件与优先级可以共同支持两条知识，允许并列或 unknown。

所有场景固定同一 Topic、Goal、完整候选。Goal 为配置中的中性教育选择问题，不推导疾病、治疗获益或隐藏偏好。来源条件矩阵为模型辅助源审查，语义状态仍待独立确认；完整来源和 Span 提供给评审，模型结论、条件预期值与优先级期望不提供。

## 个人情境与时间边界

新命名空间 `c1-day5-source-context-v01`，不向原 288 Probe 添加变量。最小四项为：自述文中列举的睡眠困扰、常常感觉睡眠有困难、对睡眠有困扰/担忧、一天较晚时候摄入咖啡因。保留 YES/NO/UNKNOWN，不按每周几次、持续几周或晚于几点自动定义；来源没有这些数字。其他行为、发生时间、午睡事件及来源 20 分钟建议作为必要测量清单或可选事件，不变成个体推荐阈值。

原 12 个真实窗口全部保留新变量 NOT_COLLECTED。现有 sleep_duration 14 日 mean 只作为固定的描述背景；完整 Day 5 允许记录为这项 Probe 加全部新情境字段，独立于 A/B/C/D。

自述记录必须有真实人声明、记录来源、参考时段、报告时间和观察截止时间，使用新 episode ID。主要资料要求报告/参考结束均不晚于截止；今天的回忆不能伪装成旧窗口当时的观测。没有可核验同期资料时，旧窗继续未知。新前瞻采集使用新 episode；不自动对外发送问卷或联系参与者。

未来最小前瞻采样按前三名实际同意参与者的首次两次合格 episode，按入组与记录时间先后取样，不筛症状、方向或偏好；采集目标不是必须产生差异。尚未入组、采集或安排真实参与者。

## 合成机制边界

六个明确虚构场景只检查测量表示、三值条件、同一初始状态的 C/D、未知预算和盲审流程。四个为 often-trouble × late-caffeine 的 2×2，两个将其中一个字段改为 UNKNOWN。其余选定困扰与担忧固定为 NO；不推断完整临床状态。没有来自期望排序的数值、方向或 qrels；来源仅支持这些条件/行为可以被表述，不能替它们生成推荐排序。

真实资料与合成机制分别统计。两个评审包都明确标记数据类型，不能把虚构自述附到真实 WearableQA 参与者身上。

## 评审与裁决

两名不同真实评审，各 18 个场景×primary/mirror/exact-repeat＝54 包。每人独立、别名与顺序不同，三个 session 分开交付；预设间隔至少 48 小时仅控制重复记忆。隐藏原标签、Ranker、预计收益、场景配对、镜像/重复映射及另一人的回答。每人先独立核对两条完整来源，再评价。

评判轴分开：Topic/Goal 的教育相关性、来源动作线索与个人证据的对应、相对信息优先级 LEFT/RIGHT/TIE/UNKNOWN、缺失的具体上下文。没有经核验的知识级硬性适用门槛；评审不能据选定线索推导诊断、全局不适用或强制优先级。每项有源 Span、Evidence ID 与解释；证据缺失允许引用缺失状态，但不得用它肯定症状或否定条件。

真实身份和独立性只能由实际人声明，程序不证明其物理身份。模板不预填人名、身份声明、评分、优先级或来源通过。拒收 AI 自报、空模板、同一身份、见过旧输出或另一评审答案的“独立评审”。本轮不调用 Qwen 填表。

先检查同一人三视图的 canonical 偏好完全一致，再检查两人一致；不同等级但同偏好也保留为质量问题，效用需等级一致。没有多数投票或自动修答案。同人不稳定保留待审，第三人不能将它“裁决成稳定”；两人稳定而不同的案例交给第三位不同真实人，保留原分歧及裁决依据。

## 五阶段与效用门槛

逐项报告：①来源条件—动作关系是否存在，以及真实条件是否观测成立；②测量是否可操作、实际是否采集；③独立参考是否可靠；④固定 Goal 下是否存在事实支持的优先级差异；⑤获取是否带来效用。

至少四个具有实采情境的主要真实 episode、两名参与者，且来源检查、双评审、镜像和重复检查通过，才可称有限样本参考可用于后续诊断。必须先固定实际情境和 Ranker，再做效用；这里不设源条件→排序权重，也不因没有排序信号而调整 rubric。

C 为自述 often-trouble 问题，D 为晚些时候咖啡因行为问题，两者来源相关、同一处理与按回答问题数计费，UNKNOWN 仍耗 1。C 只可能改变咨询源线索的已知程度，D 可能改变习惯行动机会的已知程度；这些信息变化不等于排序收益。没有可靠参考、实采记录和另行预登记的 Ranker时，NDCG、Pairwise、Observed ΔU、Expected V 均保持 null，不把程序执行成功当闭环成立。

若缺少真实情境或真实独立评审，最终状态为 INSUFFICIENT_EVIDENCE，并明确列出外部缺口；所有可执行的源审计、协议、包、校验、三值机制和回归继续完成。不启动正式 Baseline/C2，不冻结正式 Benchmark。
